# slotjwt

Slot structured JSON jwt payloads without a heavyweight toolkit.

**Site:** https://theworker02.github.io/slotjwt/

## Install / run

```bash
git clone https://github.com/theworker02/slotjwt.git
cd slotjwt
node src/cli.js
node --test
```
